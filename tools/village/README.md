# 마을과 산 생성기

로타와 카엘룸이 사는 산자락 마을, 그리고 로타가 오르는 산을 Blender 파이썬 스크립트로 통째로 만들어내는 도구입니다.
모델 파일을 손으로 고치는 대신 스크립트를 고치고 다시 돌리면 마을 전체가 몇 초 만에 새로 만들어집니다.

## 실행

Blender 5.2 LTS 기준입니다. 저장소 최상위 폴더에서 실행합니다.

마을을 만들어 `assets/village/village.glb`(게임 엔진용)와 `village.blend`(Blender용)로 저장:

```bash
blender -b --factory-startup -P tools/village/build.py -- --export
```

미리 정해둔 시점으로 렌더링 (`assets/village/renders/`에 저장):

```bash
blender -b --factory-startup -P tools/village/build.py -- --render entrance,plaza --samples 72 --res 1600x900
```

- `--render all`: 모든 시점. 시점 목록은 `build.py`의 `CAMERAS`.
- `--backface`: 뒤집힌 면을 자홍색으로 칠해서 렌더. 게임 엔진에서 면이 사라져 보이는 문제를 찾을 때 씁니다. 깃발, 빨래, 풀처럼 일부러 양면으로 만든 것도 자홍색으로 보이는데, 그건 정상입니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `meshkit.py` | 메시 조립 도구. 상자, 기둥, 원뿔, 덩어리 같은 기본 도형과 색 함수 |
| `world.py` | 지형 높이, 계단식 단, 길, 광장, 큰 산과 주변 산, 구름 |
| `house.py` | 집 생성기. 돌 기초, 회벽과 나무 뼈대, 창문과 덧문, 휘어진 기와지붕 |
| `props.py` | 그림자극 무대, 회관 종탑, 산길 관문, 입구 아치, 노점, 등불, 울타리, 깃발 |
| `nature.py` | 소나무, 활엽수, 덤불, 바위, 풀, 꽃 |
| `layout.py` | 배치. 어떤 집이 어느 단 어디에 서는지, 광장 꾸밈, 숲 |
| `build.py` | 마을 실행 진입점. 장면 조립, 하늘과 해, 카메라, 렌더링, 내보내기 |
| `mountain.py` | 산의 네 구간(숲길, 능선, 천사의 고원, 정상)과 야영지, 구름바다 |
| `build_mountain.py` | 산 실행 진입점 |
| `test_house.py` | 집 생성기만 가까이에서 확인하는 테스트 렌더 |

## 마을 구조

- 좌표: +X 동쪽, +Y 북쪽(산 방향, 오르막), +Z 위. 단위는 미터.
- 남쪽 입구에서 북쪽 산길 관문까지 다섯 단으로 올라갑니다. 단 사이는 돌 축대이고, 가운데 큰길이 돌계단으로 이어집니다.

| 단 | 높이 | 있는 것 |
|---|---|---|
| 0 | 0 m | 입구 아치, 여관, 농가, 헛간, 밭 |
| 1 | 4 m | **로타의 집**(텃밭, 빨랫줄, 훈련용 허수아비), 빵집, 집 4채 |
| 2 | 8 m | **광장**, **그림자극 야외 무대**, 마을 회관과 종탑, 노점, 벚나무, 가게, 집 3채 |
| 3 | 12.5 m | 대장간, 집 5채 |
| 4 | 17 m | **카엘룸의 집**(늙은 나무와 그네, 추모석), 집 1채, **산길 관문** |

관문 너머로는 돌무지와 하늘색 깃발이 이어지는 산길이 숲을 지나 큰 산으로 올라갑니다.

## 내보낸 파일의 오브젝트

`village.glb` 안에는 이름 붙은 오브젝트 34개가 들어 있습니다.

- 건물: `Rota_House`, `Caelum_House`, `Village_Hall`, `Shadow_Stage`, `Mountain_Gate`, `Entry_Arch`, `Inn`, `Bakery`, `Shop`, `Smithy`, `Farmhouse`, `Barn`, `House_A` ~ `House_M`
- 환경: `Terrain`, `Mountains`, `Clouds`, `Forest`, `Trees`, `GroundCover`
- 꾸밈: `Stonework`(축대, 계단, 광장 바닥돌), `Props`, `Bunting`

## 게임 엔진(Godot)에서 쓸 때

- 색은 텍스처 없이 **정점 색**(`COLOR_0`)으로만 칠했습니다. 재질은 2개뿐이라 모바일에서 가볍습니다.
- 재질에서 "정점 색을 알베도로 사용"이 켜져 있어야 색이 보입니다. Godot은 glTF를 불러올 때 보통 자동으로 켭니다.
- 전체 약 44만 삼각형입니다. 저사양 폰을 고려하면 `Forest`, `GroundCover`, `Clouds`에 표시 거리 제한을 거는 것부터 시작하면 됩니다.
- 충돌체는 아직 없습니다. `Terrain`과 `Stonework`는 메시 그대로, 집은 상자로 잡는 것을 권장합니다.
- 하늘과 해는 Blender 렌더용 설정이라 내보내지지 않습니다. 엔진에서 따로 설정해야 합니다.

## 산

산은 한 덩어리가 아니라 **네 구간의 맵**으로 나뉘어 있습니다. 구간마다 파일이 따로 나옵니다(`assets/mountain/<구간>.glb`).

네 구간을 모두 만들어 내보내기:

```bash
blender -b --factory-startup -P tools/village/build_mountain.py -- --zone all --export
```

한 구간만 렌더링 (`assets/mountain/renders/`에 저장):

```bash
blender -b --factory-startup -P tools/village/build_mountain.py -- --zone plateau --render all --samples 64
```

| 구간 | `--zone` | 내용 |
|---|---|---|
| 숲길 | `forest` | 관문 위로 이어지는 소나무 숲 오르막. 개울과 나무다리, 버섯과 쓰러진 통나무, 마을이 내려다보이는 전망 바위 |
| 능선 | `ridge` | 3일차 아침. 구름바다 위로 뻗은 꽃밭 능선, 야영지(불 꺼진 모닥불), 하늘을 올려다보는 너럭바위 |
| 천사의 고원 | `plateau` | 구름 위의 폐허. 해 문양 바닥과 무너진 흰 기둥 고리, 정상으로 가는 부서진 아치와 돌계단, 마지막 밤의 야영지(펼쳐진 일지와 등불) |
| 정상 | `summit` | 눈 덮인 꼭대기. 아무것도 기다리지 않는다. 납작한 바위 하나와 바랜 하늘색 천이 걸린 낡은 장대뿐 |

- 각 구간은 +Y가 오르막이고, 길은 남쪽에서 들어와 북쪽으로 나갑니다.
- 오브젝트 이름은 `Forest_Terrain`, `Ridge_Props`처럼 구간 이름이 앞에 붙습니다. `*_Backdrop`(먼 산과 발아래 마을)과 `*_Clouds`(구름바다)는 걸어갈 수 없는 배경입니다.
- **안개는 정상에만** 있습니다. 렌더에서는 Blender의 볼륨 안개를 썼고, 이 안개는 내보낸 파일에 들어가지 않습니다. 게임에서는 엔진의 안개 기능으로 정상 구간에만 켜야 합니다. 고원에서 올려다보이는 정상의 구름 모자는 메시라서 파일에 들어 있습니다.
- 숲길과 능선에서 내려다보이는 마을은 상자와 지붕만으로 만든 간략한 원경 모형입니다.
